How to exchange files
  1. Select your files or a folder and archive options. Browser download needs no destination folder.
  2. Create the ZIP, then transfer it by USB, cloud storage or another method. Share the password separately.
  3. Open the ZIP with 7-Zip or select “Extract archive” on this page. For an unencrypted ZIP, leave the password blank.

Everything runs locally. No account, Python, server or network connection is required. The ZIP and compression libraries are included in this HTML file.

Choosing archive options

Deflate + Normal (5) is a general-purpose default. Fastest (1) favours speed; Ultra (9) tries harder to reduce size. Higher levels do not guarantee a smaller archive. For video, photos or other files that are already compressed, choose Store.

AES-256 is the recommended encryption setting. AES-128 is also supported. ZipCrypto is weak and intended only for legacy compatibility. None creates an ordinary ZIP without password protection. Built-in operating-system extractors do not always support AES-ZIP.

Automatic ZIP64 enables the format extension when needed. Always forces it for all entries. Off uses classic limits and rejects jobs with files or estimated output too large for those limits. The optional verification pass checks the saved archive, adding an extra read.

Choices are kept while switching between Create and Extract, but reset when the page is reloaded. Passwords are never saved.

Large files and supported formats

Browser download temporarily holds the ZIP in memory and is limited to 256 MiB of source data and ZIP output. Select Direct to disk for larger archives; that mode processes contents in small blocks and writes directly to disk. Keep enough free space for the output. The file list uses additional memory; the limit is 200,000 entries. FAT32 cannot store individual files of 4 GiB or larger.

Extraction first checks all file contents, then reads the archive again to restore them. Source files must not change during processing. Normal files and folders, including empty files and subfolders, are supported. File permissions, links, original timestamps and special system attributes are not restored.

This page reads ZIPs with Store or Deflate compression, including AES and ZipCrypto encryption, and legacy .tresorweb archives. It does not open .7z files, split ZIPs, Deflate64 or old Python .tresor files.

Security and limits

Encrypted ZIPs protect file contents, not names, folder structure or sizes. ZIP metadata is not cryptographically authenticated. Removing whole entries or changing names cannot reliably be detected by the ZIP format alone.

zip.js 2.23.0 and its embedded JavaScript Deflate compressor are bundled locally. No external code is loaded. The application has not been independently security-audited.

Normal errors and cancellation attempt to remove new incomplete output. Closing the tab, quitting the browser or losing power can leave extracted files behind. Keep the page open until completion or confirmed cancellation. Original files remain unchanged. This tool does not replace a backup.
